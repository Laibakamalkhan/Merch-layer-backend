# Shopify AI Analytics — Debug/Fix Report

## Findings

1. Gemini TLS/transport failures and valid Gemini HTTP 503 responses were previously surfaced through the same generic RuntimeError path. They are now distinct:
   - `GeminiTransportError` -> API 502
   - `GeminiAPIError` -> preserves the real provider HTTP status/body (e.g. 503)
   - transient 429/5xx and transport failures remain retried.
   - Gemini requests use `Accept-Encoding: identity` and `Connection: close`.

2. RAG semantic retrieval now requires both `document_chunks.tenant_id` and `documents.tenant_id` to match the requested tenant. No RAG data is deleted.

3. One-row SQL aggregates are now represented as dashboard KPI `aggregation: "value"` so the frontend does not conceptually re-aggregate an already aggregated database result. Dashboard columns not present in SQL results are discarded.

4. Dashboard charts were being generated by the backend but ignored by the chat UI. A dependency-free renderer was added for line/area/bar chart specs.

5. Workspace chat now defaults to Shopify instead of Amazon.
